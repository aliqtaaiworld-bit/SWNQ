SWNQ

SWNQ is a Progressive Web App (PWA) designed for a fast, simple, and mobile-friendly experience.

Features
📱 Progressive Web App
🌐 Works on mobile and desktop
⚡ Fast and lightweight
🔒 HTTPS-enabled hosting
📲 Can be installed on supported devices
Technology
HTML
CSS
JavaScript
PWA
Service Worker
Installation

Open the SWNQ website on a supported mobile browser and select Add to Home Screen or Install App.

Project

This repository contains the files required to run and deploy the SWNQ Progressive Web App.
